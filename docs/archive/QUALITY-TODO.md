- [x] **A1 实测 `auth login --resume`。** 在一个确因 `auth-expired` 而等待的测试 Run 上交互登录，测量从提示到 Run 继续的时间与人工操作次数。
  - 依赖：真实过期 Run 与可交互登录的测试账号。
  - 结果：同一只读 Run `5dfd5442-b8ae-490f-832e-85e26cc9d6b7` 在交互登录后恢复，约 12 秒完成下一次页面采集；人工操作为填手机号、填密码、点击登录 3 次。Run 后续停在文案输入，提交文案块后成功发布。认证快照留在用户级私有缓存；该 Run 没有业务写动作。
  - 完成条件：原 Run 继续且此前成功的任务未重做；认证状态仅在用户级私有缓存；日志和项目产物不含 Cookie、token、完整会话 URL。
