## 兼容与限制

- 不声明 variants / profiles 时沿用原行为。旧变体缺 scenarioRevision 需重采；旧任务缺环境指纹时视觉不可比，不能当作无漂移。
- 修复预算默认仍 2；配置范围之外拒绝。字段仅提示，不删除、不改变执行语义；提示不进入模型修订内容。
- persistRaw 默认 true 兼容旧项目；false 的缓存键与原模式隔离，raw 路径为 null，--out 只导出通过隐私检查的安全图；没有安全图时拒绝导出。
- false 不代表永不落盘：派生仍用临时 staging，正常提交 / 中止清理，强制中止的残留按现有恢复 / GC 处理；旧原图不自动删除。
- 无原图时不能离线重新派生；在线安全主体可重采，写任务须确认业务状态再显式 --refresh。原图不是发布 / 同层在线视觉比较的必要输入。
- R7–R9、NeoAgent 现场验收、Linux / Windows 复验未做。本轮未降低隐私、授权、Fixture 或发布门禁。
