## 兼容与偏离

- CSS 字符串继续支持；角色对象只接受 role / name，精确匹配，全部命中替换。缺目标 / 无法审计拒绝；临时标记不写被采集项目源码。Shadow DOM 的定位能力不代表可审计，保持门禁。
- 无 result 的旧任务不改正文；结果生成 step-result-<stepId>，参与 definitionRevision、审批与 update，claims 质量计数包含步骤结果；result 文案做现有风格检查，审批入口拒绝跨 after 状态引用，live 保留执行状态并重算，completion 章节只汇总自己引用的声明。失败仍 claim-failed 阻断；Fixture 为 simulated，不冒充真实后端完成。
- 旧语义摘要缺 locator 信息保持旧格式可读，不补造关联；semantic hash 仍按角色 / 名称 / 层级计算。
- pipeline quality-4 使旧采集缓存失效，历史发布结论不改写；不放宽写步骤自动重放限制。persistRaw 默认 true、关闭时 null raw 路径兼容不变，data.revision 保留缓存失效语义。
- R9 未修改生产 emitter 或警告逻辑；现有连续空格归一化行为保留，用实际读回结果证明警告，不自动接受漂移后的定义。
