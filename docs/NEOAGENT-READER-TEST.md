## 观察步骤

1. 测试前确认三篇手册能打开、发布图能显示，给读者有效的测试账号。账号与认证状态由读者本人输入，不记入本表。
2. 每篇从读者打开手册开始计时。读者说“完成”时停表；15 分钟仍未完成记为超时。若有多位读者，轮换任务顺序以减少熟悉界面带来的影响。
3. 观察者只记录读者停顿、误点、原话和求助，不提醒下一步。读者问“在哪里点”或需要观察者代操作时，记录为求助；此后完成也不计为独立完成。
4. 让读者指出手册所写的完成判断。观察者按当前界面逐项核对：助手回复和卡片、余额与明细、题目预览的内容和数量分别记录，不把“有回复”推断成“内容符合需求”，也不把“筛选已选中”推断成“已看到消耗记录”。
5. 记录脱敏摘要，不保存 Cookie、token、手机号、完整会话 URL 或真实题目内容。提交后无回复时按手册处理，不重复发送以求通过。
